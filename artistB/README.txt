新制作展 デジタルアーカイブ／作家B サンプル

【表示方法】
ZIPを展開し、index.htmlをブラウザで開いてください。VS Code + Live Serverでも表示できます。

【構成】
index.html：作家Bプロフィール・作品・出展歴
css/style.css：デザイン・スマートフォン対応
js/main.js：作品画像の拡大表示
img/：肖像・作品・QRコード画像

【注意】
作家Bの氏名、経歴、受賞歴、作品名、素材、寸法、解説、画像はすべて架空の企画用サンプルです。実在の作家・作品情報として使用しないでください。
QRコードは https://example.com/artists/artist-b/ の仮URLです。実際に公開するURLに差し替えてQRコードを再発行してください。
正式運用前に、作家本人の掲載許可を得た肖像・作品写真へ差し替えてください。
